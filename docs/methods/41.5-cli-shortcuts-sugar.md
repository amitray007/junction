# 41.5 — CLI Full Access: shortcuts (saved commands)

**Builder: Sonnet.** Depends on 41.1 (`shortcuts` field on full-access connection) + 41.3 (provider serves shortcuts as declared tools). Design: `docs/specs/2026-07-16-cli-exploratory-mode.md` §4 Layer 3, Fable Q6.

## What / why

On a Full CLI access platform, let the user pin **named shortcuts** — saved commands (e.g. "list my PRs" → `gh pr list --json ...`) that surface as their own MCP tools alongside `execute`/`help`. This is the old declared-`CliTool` model, now OPTIONAL sugar. The schema (41.1) + provider (41.3) already support it; this slice is the editing surface.

## Interfaces

- **Web:** on a full-access platform's detail/edit view, a "Shortcuts (saved commands)" section (Fable Q6 label) that lets the user add/remove `CliTool` shortcuts — reuse the EXISTING declared-tool card UI (`packages/web/src/routes/-components/cli-form/tool-card.tsx` etc.) verbatim; it already builds a `CliTool`. The only difference is these live in `connection.shortcuts[]` (full-access) instead of `connection.tools[]` (declared).
- **CLI:** `junction platform cli-shortcut add --platform <id> --descriptor '<CliTool json>'` (+ `--json`) and a `remove` counterpart, so agents can manage shortcuts headlessly. (Or fold into the existing platform edit path if cleaner.)
- Persistence: shortcuts ride the same `platforms.cli` column (they're part of the full-access `CliConnection`). `upsert` replaces wholesale as today.

## Files

- **Edit** web cli-form to render/edit `shortcuts` on full-access platforms (reuse tool cards).
- **Edit** `packages/cli/src/commands/platform.ts` (+ test) — shortcut add/remove headless path.
- Tests: adding a shortcut to a full-access platform makes the provider expose it as a named tool (integration with 41.3); removing it drops it.

## Constraints

- Reuse the declared-tool card + `CliToolSchema` — do NOT fork a parallel editor.
- Shortcuts are optional; a full-access platform with zero shortcuts is valid (just `execute`+`help`).
- `docs/rules/` + `docs/rules/web.md`.

## Proof-of-done

- A user can add a `gh pr list` shortcut to the gh full-access platform; it appears as `<ns>__<shortcut>` alongside `execute`/`help`; removing it works. `--json` headless path works.

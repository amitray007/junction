# 41.4 — CLI Full Access: binary discovery + install flow

**Builder: Sonnet.** Depends on 41.1 (schema) + 41.2 (extractor, to run at install). Design: `docs/specs/2026-07-16-cli-exploratory-mode.md` §5 Q1/Q3/Q6.

## What / why

Let a user install a CLI **by name** (`gh`) with Full CLI access: Junction discovers the binary, recommends one, extracts its schema at install (sandboxed), and stores a full-access `CliConnection`. No per-tool authoring.

## Interfaces

### 1. Binary discovery (core) — new file `packages/core/src/sources/cli/discover.ts`

```ts
export type BinaryCandidate = { name: string; path: string; realpath: string; version?: string; source: "path" | "common-dir" }

export function discoverBinary(name: string): ResultAsync<BinaryCandidate[], DiscoverError>
```
- Validate `name` is a bare command (`^[a-zA-Z0-9][a-zA-Z0-9._-]*$`) — reject slashes/metachars (no path traversal via the name).
- Search **PATH** (split `process.env.PATH`) then **common dirs** (`/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`, `~/.cargo/bin`, `~/go/bin`), in that order. Check the executable bit (`fs.access` X_OK) — async only, no `*Sync`.
- Dedupe by `realpath`. Order: PATH hits first (in PATH order), then common-dir-only hits. **Recommendation = first entry** (Fable Q1: "what your shell would run", NOT highest version).
- `version`: best-effort — run `<path> --version` **through the sandbox** (no creds/net) with a short timeout; parse a version-looking token; omit on failure. (Reuse 41.2's safe-probe policy shape. Do not block discovery on version.)
- Never execute unsandboxed. Typed `DiscoverError` (`{kind:"invalid-name"}` etc.). Returns `[]` (not an error) when nothing found.

### 2. Install assembly (core or platform-orchestration)

A function that, given a chosen `BinaryCandidate` + optional credentialEnvVar + a base `CliPolicy` (sensible default: cwd = a per-platform scratch dir under JUNCTION_HOME runtimeDir, readPaths=[cwd], writePaths=[cwd], allowNet = user-provided or []), runs `extractCliSchema` (41.2) via `createSandbox()` and returns a full-access `CliConnection` ready to `upsert`. Persist the **realpath** as `binaryPath`.

> Default policy note: most useful CLIs need network (gh → api.github.com:443). The install flow should let the user provide a net allowlist; default `[]` with a clear "no network" indication. Keep the default SAFE (no net, scratch-only fs); the user widens it. This matches Junction's sovereignty posture.

### 3. CLI headless path (`packages/cli/src/commands/platform.ts`)

Add a scriptable path so agents can drive it:
- `junction platform add --kind cli --name gh --full-access [--net api.github.com:443] [--credential-env GH_PAT] [--json]`
  - discovers, auto-picks the recommendation (or `--path <abs>` to override / for the manual escape hatch), extracts, upserts.
  - `--json` prints the candidate list + chosen path + tool/ node counts (headless-friendly).
- Keep the existing `--descriptor` declared path working.

### 4. Web install panel (`packages/web`)

Extend the CLI add flow (`packages/web/src/routes/-components/cli-form/` + `platform-mutations.server.ts`):
- A mode toggle: **"Access: Declared commands (default) / Full CLI access"** (Fable Q6 exact wording).
- Full CLI access sub-flow:
  1. Text input: binary name (`gh`). A server fn calls `discoverBinary` → returns candidates.
  2. Show candidates (path + version + source), recommendation preselected; a "enter path manually" escape hatch.
  3. Optional network allowlist + credential env var input (credential value bound via the existing credential flow — do NOT collect the secret in this form beyond the existing mechanism).
  4. The install confirmation line (Fable Q3/Q6): *"Junction will run `gh`'s `--help` tree — sandboxed, offline, no credentials — to learn its commands."* Plus the Full CLI access explainer copy from the spec.
  5. On submit: server fn discovers→extracts→upserts; show a summary ("Mapped N commands to depth D; X branches deferred").
- Follow `docs/rules/web.md` (server-only-core boundary, design tokens, semantic HTML/a11y, credentials metadata-only). Match the existing app-connect visual language — no AI-slop.

## Constraints

- Binary name validated (no path chars); discovery never execs unsandboxed (version probe is sandboxed).
- Persist realpath; scriptable `--json` path for agents.
- Default policy safe (no net, scratch fs); user widens. No sync fs in core.
- `docs/rules/` + `docs/rules/web.md`.

# 30.14 — UI completion: Category facet + Recent Activity link

`listApps()` returns the legacy `AppDefinition` projection which drops `help` entirely, so the index page never sees categories. `listCatalogEntries` is already exported from `@junction/core` (core/src/index.ts:96) — consume it in web; no core edit.

- `packages/web/src/server/data.server.ts`:
  - `AppMeta` (line ~391) is currently `export type AppMeta = AppDefinition` — replace with an explicit interface mirroring the `AppDefinition` fields the web actually uses, plus `category?: string[]` (routes never see a core type directly — same convention as audit.server.ts's header).
  - `readApps()` (line ~483): left-join category by id:
    ```ts
    const categoryById = new Map(listCatalogEntries().map((e) => [e.id, e.help?.category]))
    const catalog = listApps().map((app) => ({ ...app, category: categoryById.get(app.id) }))
    ```
  - Add `listCatalogEntries` to the existing `@junction/core` import block (getCatalogEntry is already imported at line 15).
  - `data.functions.ts` re-exports `AppMeta` generically — no change needed.

## Change 2 — Category facet on app.index.tsx
Mirror the Status/Method facet pattern exactly (module-level options const, `useState(ALL_FILTER)`, AND-composed predicate, `<FacetSelect>`):
- `AppCardData` (line ~42): add `category?: string[]`; map it in the `cards` useMemo (line ~134).
- `CATEGORY_OPTIONS`: **derive the option list at module scope from the data if cheap, else hardcode** the currently-shipped set — Productivity, Communication, Developer, CRM, Observability, Search, Social — **plus** `{ value: "uncategorized", label: "Uncategorized" }`. Prefer deriving from the loaded apps (unique sorted categories present in `cards`, computed in a useMemo) so a future catalog category shows up without a code change — but only if it stays simple; hardcoding with a comment pointing at the catalog is acceptable.
- Predicate: `categoryFilter === ALL_FILTER ? true : categoryFilter === "uncategorized" ? (!app.category || app.category.length === 0) : (app.category?.includes(categoryFilter) ?? false)` — AND-composed with statusOk/methodOk; add to the deps array.
- `isFiltered` (line ~193): add `|| categoryFilter !== ALL_FILTER`.
- JSX: third `<FacetSelect ariaLabel="Filter by category" allLabel="All categories" ... />` right after the Method facet (line ~222-229).
